# Умна къща

Това е конзолна програма на C#, която управлява умна къща с лампа, термостат и колона. Програмата проверява колко е часът и според това дали е сутрин, ден, вечер или нощ включва или изключва устройствата и настройва температурата. Накрая показва състоянието на всяко устройство.

В проекта се използват класове, наследяване (всички устройства наследяват `SmartDevice`) и интерфейсът `IControllable`.

## Стартиране

В папката на проекта:

```
dotnet run
```
